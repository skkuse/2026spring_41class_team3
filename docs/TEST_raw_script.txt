제목: MARS 개발 회의

목적: 회의록 요약과 액션아이템 생성 흐름 점검 및 앞으로 계획

회의록 원문: MARS 개발 회의에서 김도현, 이채연, 장정우, 조아정은 회의록 업로드 후 요약과 액션아이템이 생성되는 흐름을 점검하였다. 이채연은 회의록 상세 화면에서 요약 내용과 액션아이템 목록이 한눈에 보여야 하며, 사용자가 담당자나 상태를 바로 수정할 수 있으면 좋겠다고 말했다. 김도현은 백엔드에서 액션아이템의 담당자, 상태, 우선순위를 부분 수정할 수 있도록 PATCH API를 확인해보기로 했다. 장정우는 담당자가 지정되지 않은 액션아이템도 삭제하지 말고 “미정” 상태로 남겨두는 방식이 실제 회의 데이터에 더 적합하다고 의견을 냈다. 조아정은 테스트 데이터에 담당자가 있는 항목과 없는 항목, 마감일이 있는 항목과 없는 항목이 섞여 있어야 AI 추출 성능을 확인하기 좋다고 말했다.

회의 중에는 업로드된 회의록 텍스트가 길어질 경우 요약 품질이 떨어질 수 있다는 점도 논의되었다. 이채연은 긴 회의록에서도 핵심 결정사항과 할 일을 구분해서 보여주는 것이 중요하다고 했고, 조아정은 다음 테스트에서 회의록 길이를 다르게 만든 샘플을 준비하기로 했다. 김도현은 현재 API 응답 구조에서 액션아이템의 assignee 값이 null일 때 프론트엔드에서 오류가 나지 않는지 확인해야 한다고 말했다. 장정우는 마감일이 없는 액션아이템은 빈 값으로 두기보다 화면에서 “마감일 미정”으로 표시하는 방안을 검토해보자고 제안했다.

마지막으로 팀은 다음 개발 단계에서 회의록 상세 페이지 개선, 액션아이템 수정 기능 점검, 담당자 미지정 항목 처리, 다양한 샘플 데이터 추가를 진행하기로 했다. 이채연은 상세 화면 UI 구조를 정리하고, 김도현은 PATCH API 동작을 점검하며, 장정우는 담당자 미지정 항목 표시 방식을 확인하기로 했다. 마감일이 없는 액션아이템 처리 방식과 긴 회의록 테스트 데이터 추가는 아직 담당자를 정하지 않고 이후 회의에서 다시 논의하기로 했다.
